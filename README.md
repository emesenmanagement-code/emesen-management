# Emesen Management website

Upload the CONTENTS of this folder to the root of the GitHub repo (not the folder itself).

Repo root must look exactly like this:

```
index.html
support.js
README.md
assets/
  client-finwise.png
  founder.png
  hero-planning.jpg
  logo-*.png
  speaker-kadochi.jpg
  speaker-kapalu.png
```

Checklist
- `assets` is lowercase and sits next to index.html (not inside `emesen-site/`).
- Filenames are lowercase; Netlify is case-sensitive.
- Commit to `main` directly, or merge any open pull request.
- Netlify: Publish directory blank (or `.`), no build command.
